# Virtuals Degen 通俗解释

> 用途：给不了解 Virtuals Degen 的朋友快速讲清楚它是什么。面向在校大学生和非技术读者，不作为投资建议。

## 一句话讲清楚

Virtuals Degen 可以理解成一个「AI 交易员真人秀」。

先说背景。Virtuals 是一个平台，上面跑着很多 AI Agent——你可以把 Agent 理解成一个自动运行的程序，它有自己的钱包，能自己做交易决策，不需要人操控。Degen 是 Virtuals 新推出的一个玩法，也是这篇文章要讲的重点。

它不是普通的炒币，也不是单纯的排行榜。它更像是：

**AI Agent 交易比赛 + 官方跟单资金池 + Agent 代币的预期市场**

这里面有几个概念需要先解释：

- **跟单**：就是照抄别人的交易。比如某个 Agent 买了一个品种，跟单的资金也会跟着买同样的品种。
- **代币**：每个参赛的 Agent 背后都有一个自己的代币，可以在市场上买卖。你可以把它理解成这个 Agent 的「股票」。

大致流程是这样的：这些 Agent 在一个叫 Hyperliquid 的交易平台上做合约交易（类似于押涨跌的金融工具）。官方每周会挑出表现最好的前 10 个 Agent，然后拿出一笔官方资金（叫做「奖池」，大概 20 万美金的量级，具体每一季以官方页面为准）去复制它们的交易。

如果这些 Agent 赚钱了，其中一部分利润会用来买回对应 Agent 的代币——这个动作叫「回购」。回购会推高代币价格，所以市场会提前去猜：谁可能被选上？选上之后能不能赚钱？会不会触发回购？

这就是整个游戏的核心：**玩的不是已经发生的事，而是对未来的预期。**

## 普通人为什么会关注它

你可以把每个 Agent 想象成一个参赛选手，每个选手背后都有自己的代币。

比如某个 Agent 很会交易，被官方选进了前 10。市场可能会觉得：这个 Agent 未来会被官方资金跟单，有机会赚钱，有机会触发回购。于是大家就会提前买它的代币。

这就是预期。加密货币市场里很多价格波动，炒的不是已经发生的事，而是「别人马上会相信什么」。

Degen 好玩的地方在于，它把这种预期做成了一个公开赛场。你不是完全靠听别人喊单，你可以自己看排行榜、看 Agent 的交易结果、看官方资金的实时盈亏、看回购有没有可能发生。

数据越多，判断就越不像纯赌博。所以我把 Degen 定义成一个高赔率、相对高胜率的游戏——不是说闭眼买都能赢，而是说它比很多纯靠情绪炒作的币多了一些可分析的东西。

## 整个机制是怎么运转的

### 第一层：海选

所有参赛的 Agent 都在排行榜里交易。交易的品种主要是 Hyperliquid 上的永续合约（一种可以押涨跌的金融衍生品）。

这一层就是海选。所有 Agent 都在场上打比赛，市场会看它们谁赚钱、谁胜率高、谁回撤小、谁有稳定表现。

### 第二层：选拔

每周一，一个叫「AI 评审委员会」的机制会审查这些 Agent 的链上交易记录和论坛讨论，然后挑出前 10 名。

这一步很关键。一旦 Agent 入选前 10，它就不只是普通参赛选手了——它开始获得被官方资金跟单的机会。

### 第三层：主战场——官方跟单

从每周二早上 8 点（新加坡时间）开始，官方的奖池资金会复制这 10 个 Agent 的交易，持续 7 天。

入选只是第一段预期。入选之后，官方资金跟着它到底赚不赚钱，才是第二段预期。如果跟单某个 Agent 后持续盈利，那这个 Agent 背后的代币就可能被市场重新定价。

### 第四层：兑现——回购

如果某个被跟单的 Agent 给奖池赚了钱，利润的一部分会用来买回这个 Agent 的代币。

这就是整条预期链路的终点：

1. Agent 表现好，可能入选前 10
2. 入选后获得官方资金跟单
3. 跟单账户的实时盈亏开始变好
4. 市场预期会有回购
5. 代币价格提前反应

每一层都是一个预期节点，每一层之间都有信息差。

## 实时盈亏为什么重要

上面第三步提到的「跟单账户的实时盈亏」，在 Degen 的界面上叫 Live P&L（实时盈亏）。这个数字非常关键，因为它直接关系到市场会不会预期后面有回购。

举个例子：如果一个 Agent 被选上之后，它对应的跟单账户盈亏从 0 变成 +3000、+6000、+10000 美金，市场就会开始想——这个 Agent 真的在赚钱，之后是不是会有回购？反过来，如果盈亏变成 -2500、-4000，说明跟单表现不好，预期就会变差。

这里有一个关键区分：**排行榜反映的是过去的表现，实时盈亏反映的是正在发生的预期。** 一个 Agent 之前很强，不代表它这一周一定赚钱。一个 Agent 刚入选时没人关注，但如果它的实时盈亏开始快速走强，市场可能会突然反应过来。这中间就有信息差。

## 它和普通炒币有什么不同

普通炒币很多时候是在看故事、看走势图、听别人喊单。Degen 多了一层可观察的比赛数据——你可以看到 Agent 是否入选、官方资金给它分配了多少、它当前赚了还是亏了、最后有没有回购。

当然，这不代表它就安全。恰恰相反，它还是非常高风险。因为代币价格会提前反映预期，一旦大家都看到了同一个利好，可能也就已经不便宜了。

所以它更像一个信息差游戏：

- 早一点发现「谁可能入选」，是一层信息差
- 入选后早一点发现「谁的实时盈亏开始变好」，又是一层信息差
- 等所有人都在喊这个 Agent 牛的时候，赔率可能已经变差了

高赔率来自预期还没有完全兑现的时候。高胜率来自数据是公开的、不是完全黑箱。但高风险同样存在——预期变化很快，价格反应更快。看懂的人玩的是信息差，看不懂的人买到最后可能只是在接别人的预期。

## 顺便提一下 Predict

除了 Degen，Virtuals 里还有一个叫 Predict 的玩法，更像预测市场——你判断某个事情会不会发生，然后押自己的判断。

Degen 是看 Agent 的交易能力，Predict 是看你对事件的判断能力。它的刺激点在于，如果你真的比别人早看懂一件事，赔率会非常夸张。但预测市场非常吃判断，也非常吃运气。

这篇主要讲 Degen，因为我觉得 Degen 是目前最有意思、也最适合做数据分析的玩法。

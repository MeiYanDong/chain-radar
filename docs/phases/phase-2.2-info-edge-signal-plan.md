# Phase 2.2 Plan：15min 信息差信号

> 维护规则：本文档是 Phase 2.2 的产品计划。它描述用户判断链路和产品取舍，避免写成代码清单。

## 1. 阶段目标

让 Pot Monitor 更快捕捉 Copy-trading Live P&L 的变化。

用户关心的不是 P&L 数字本身，而是它背后的预期变化：如果某个 Agent 的 Live P&L 在短时间内快速扩大或恶化，市场对相关代币的预期可能正在改变，价格可能还没有完全反应。

## 2. 用户观点演变

- 最早跟随 efo 老师买币。
- 后来做大户持仓工具，看 top 3 代币的大户买入金额、已实现收益、未实现收益。
- 再后来意识到大户成本不是主线，真正重要的是代币未来预期。
- 当前重心转向 Copy-trading Live P&L 的变化量，因为它可能先改变用户对代币的预期，再传导到买卖行为，最后影响价格。

## 3. 产品原则

- 15min 是信息差窗口，不是噪音窗口。
- 快速提醒优先于复杂复盘。
- 1H 信号用于趋势确认，不能替代 15min。
- 冷却只防重复，不阻止信号升级。
- 心态、信心、贝叶斯和凯利拆分到 Phase 2.3，不阻塞提醒速度。

## 4. 当前范围

- 保留 Live P&L 绝对值阶梯提醒：`±2,000 / ±5,000 / ±10,000 / ±15,000 / ±20,000`。
- 15min 变化量分级：`±2,000 / ±5,000`。
- 1H 变化量分级：`±2,000 / ±5,000`。
- 如果先触发 `$2,000`，随后扩大到 `$5,000`，必须再次提醒。
- 继续过滤 `currentValue=0` 或 `startingCapital=0` 的异常数据。

## 5. 暂不处理

- 不恢复大户持仓 Dashboard 常驻服务。
- 不自动交易。
- 不直接给买卖建议。
- 不在提醒前强制用户记录心态。
- 不急着做复杂模型或自动 Kelly 仓位建议。

## 6. 成功标准

- Pot Monitor 保持 7*24 运行。
- 15min `$2,000` 和 `$5,000` 信号都能被识别。
- `$5,000` 强信号不会被 `$2,000` 普通信号的冷却吞掉。
- 每条提醒能清楚说明：窗口、方向、变化量、触发档位、当前 P&L。
- 下一步可以在不影响提醒速度的前提下，进入 Phase 2.3 决策记录字段定义。
